CSS Grid Layout

Modern Two-Dimensional Web Layout System

Hello everyone. Today I will talk about CSS Grid Layout, a modern and powerful system for creating web page layouts.

What is CSS Grid?

  • Layout system in CSS
  • Works in two dimensions
  • Rows and columns
CSS Grid is a layout model that allows us to organize content both horizontally and vertically at the same time.

Why Use Grid?

  • Cleaner code
  • Flexible design
  • Better alignment
  • Responsive layouts
Grid makes layouts easier to build and maintain. We need fewer hacks and less complex positioning.

Basic Concepts

  • Grid container
  • Grid items
  • Tracks
  • Gaps
The container holds the grid. Items are placed inside it. Tracks are rows and columns, and gaps create spacing.

Creating a Grid


.container {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;
}
To create a grid we set display to grid. Then we define how many columns we want using grid template columns.

Positioning Items


.item {
  grid-column: 1 / 3;
  grid-row: 1 / 2;
}
We can place items exactly where we want by specifying starting and ending grid lines.

Grid vs Flexbox

  • Grid → two dimensions
  • Flexbox → one dimension
  • Often used together
Grid controls rows and columns. Flexbox is better for alignment in a single row or column. Many projects use both technologies together.

Advantages

  • Less code
  • Better control
  • Responsive by design
  • Modern browser support
CSS Grid simplifies complex layouts and works in all modern browsers, which makes it a great choice for new projects.

Conclusion

CSS Grid makes layout design simple and powerful.
